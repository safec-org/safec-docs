# Learn SafeC

::: lead
New to SafeC? Start with the Book. Coming from C, C++, Rust or Zig? The guide's comparison and design pages explain what changes and why. Looking something up? The reference and the standard-library pages are the source of truth.
:::

## Start here {#start}

::::: cards 3
::: card book
### [The SafeC Book](/book/)

A project-driven introduction in nine chapters: installing, a first program, regions, structs and methods, enums and `match`, error handling and a final project.
:::
::: card compass
### [Guide](/guide/introduction)

What SafeC is and isn't: the [introduction](/guide/introduction), [getting started](/guide/getting-started), the [design philosophy](/guide/design) and a [comparison](/guide/comparison) with C, C++, Rust and Zig.
:::
::: card play
### [Playground](/playground)

Edit and run SafeC in the browser and load every runnable example from the Book. Programs on this site that the playground can build have a *Run in Playground* link.
:::
:::::

## Reference {#reference}

::::: cards 2
::: card list
### [Language Reference](/reference/types)

Types, operators, literals, [memory and regions](/reference/memory), functions, [generics](/reference/generics), polymorphism, [safety](/reference/safety), [C interop](/reference/ffi), concurrency, [bare metal](/reference/baremetal) and the preprocessor.
:::
::: card layers
### [Standard Library](/stdlib/)

Every std module with its API: core, collections, serialization, [async](/stdlib/async), [networking](/stdlib/net), [HTTP](/stdlib/http) and [TLS](/stdlib/tls), [GUI](/stdlib/gui), [audio](/stdlib/audio), [WebAssembly](/stdlib/wasm), ML, crypto, embedded.
:::
::: card code
### [API Reference](/api/)

Every std declaration, generated from the sources by `safeguard doc --std`: per-item pages with signatures, doc comments and source links, a module tree and search. Your own libraries get the same with [`safeguard doc`](/advanced/safeguard#safeguard-doc).
:::
::: card chip
### [Advanced](/advanced/compiler)

How the [compiler](/advanced/compiler) works, the [safety model](/advanced/safety-model), [compile-time introspection](/advanced/introspection), [scx templating](/advanced/scx) and the [package manager](/advanced/safeguard) in depth.
:::

## Examples {#examples}

::::: cards 3
::: card code
### [Examples on GitHub](https://github.com/safec-org/SafeC/tree/main/examples)

Complete projects in the SafeC repository: `async_demo`, `audio_demo`, `fullstack_demo` (a router server and a wasm client), `gui_hello`, `gui_gallery`, `gui_web` (a GUI program as a web page), `doc_demo` (a library documented with `safeguard doc`), and C++ / Objective-C dependencies.
:::
::: card gauge
### [Benchmarks](/benchmarks)

SafeC against C, C++, Rust, Zig and Go — compute kernels, allocation, collections, a web service, ML training — with the source of every program.
:::
::: card edit
### [This website](https://github.com/safec-org/safec-docs/tree/main/site)

A real program: the site you are reading is generated by SafeC — std markdown, scx templates and a SafeC-to-WebAssembly client.
:::
