SafeC **1.0.0-beta-7** was released on 2026-10-27. It is a pre-release: the language and std are still moving quickly.

It is the largest release so far: pull requests [#56](https://github.com/safec-org/SafeC/pull/56) through [#88](https://github.com/safec-org/SafeC/pull/88), everything merged since [1.0.0-beta-6](/blog/releases/v1.0.0-beta-6). [What's coming next](/blog/whats-coming-next) tracked it as it landed and has the longer write-up of each area; the [changelog](/changelog) lists every change down to individual signatures.

Install this exact release:

```bash
curl -fsSL https://raw.githubusercontent.com/safec-org/SafeC/main/install.sh | bash -s -- --version=v1.0.0-beta-7
```

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/safec-org/SafeC/main/install.ps1))) -Version v1.0.0-beta-7
```

## Highlights {#highlights}

- **A web stack** ([#57](https://github.com/safec-org/SafeC/pull/57)): [`std/http`](/stdlib/http) is a keep-alive server with a router and middleware, static files, cookies, multipart forms, server-sent events and WebSocket, plus a URL client that follows redirects and decodes gzip; `std/encoding/url` and `std/encoding/deflate` come with it, and [`std/wasm`](/stdlib/wasm) has full DOM and browser-API interop.
- **HTTPS** ([#66](https://github.com/safec-org/SafeC/pull/66)): [`std/tls`](/stdlib/tls) uses the operating system's TLS (OpenSSL, SChannel, Secure Transport) with a SafeC TLS 1.3 fallback, and `std/http` speaks `https://` and `wss://`.
- **Async** ([#61](https://github.com/safec-org/SafeC/pull/61)): [`std/async`](/stdlib/async) brings Rust's `Future` / `Poll` / `Waker` model as `goto` state machines, with timers, combinators, channels, a no-heap `LocalExecutor`, a multi-threaded `ThreadPool` and async TCP.
- **A GUI toolkit** ([#63](https://github.com/safec-org/SafeC/pull/63), [#65](https://github.com/safec-org/SafeC/pull/65)): [`std/gui`](/stdlib/gui) has an anti-aliased vector canvas with TrueType text, a widget toolkit and multi-window `GuiApp`, on X11, Wayland, Win32, Cocoa and the web, with GL ES, Metal and D3D11 presenters.
- **Audio and MIDI** ([#59](https://github.com/safec-org/SafeC/pull/59)): [`std/audio`](/stdlib/audio) is one callback API over ALSA, JACK, Core Audio, WASAPI and Web Audio, with MIDI on every platform.
- **`safeguard doc` and `safeguard publish`** ([#69](https://github.com/safec-org/SafeC/pull/69)): a rustdoc-style [API reference](/advanced/safeguard#safeguard-doc) for any package (std's is at [/api/](/api/)), and [library publishing](/advanced/safeguard#safeguard-publish) with CI, release archives and Pages docs.
- **scc** ([#70](https://github.com/safec-org/SafeC/pull/70)): a SafeC compiler written in SafeC that emits WebAssembly and reproduces itself byte for byte. It runs the [Playground](/playground) in your browser.
- **Prebuilt std in sections** ([#56](https://github.com/safec-org/SafeC/pull/56)): releases ship std compiled per platform, one archive per section, chosen with `install.sh --std=...` / `install.ps1 -Std ...`; the release binaries run on macOS 11 and glibc 2.25 or newer.
- **Versions you can check**: `safec --version` and the new `safeguard --version` both print `1.0.0-beta-7` ([#85](https://github.com/safec-org/SafeC/pull/85)).
- **Fixes**: variadic calls promote `bool` / `char` / `short` to `int`; safety-check gaps around `const &T` field writes, `->` escapes and container element references are closed; every container now drops its elements; `Typedef** x` locals parse; and Windows and macOS CI are green ([#64](https://github.com/safec-org/SafeC/pull/64), [#68](https://github.com/safec-org/SafeC/pull/68), [#71](https://github.com/safec-org/SafeC/pull/71)–[#75](https://github.com/safec-org/SafeC/pull/75), [#78](https://github.com/safec-org/SafeC/pull/78), [#79](https://github.com/safec-org/SafeC/pull/79), [#82](https://github.com/safec-org/SafeC/pull/82)–[#84](https://github.com/safec-org/SafeC/pull/84)).
- **Compiler and safeguard fixes** ([#86](https://github.com/safec-org/SafeC/pull/86), [#87](https://github.com/safec-org/SafeC/pull/87)): `__VA_ARGS__` expands to every argument; `#line` works; `atomic_cas` with `"release"` / `"acq_rel"` is valid; including a libc header twice is a no-op; safeguard links libm on Linux; a file with many `BST<..., struct>` inserts compiles in a fraction of a second instead of tens; warnings are printed again when a file comes from the incremental cache.

## Breaking changes {#breaking}

Every breaking change below is reported by the compiler at each affected line — a wrong argument count or type, an ownership error with a note at the declaration, or a missing header. Nothing changes behaviour silently except where the [changelog](/changelog) says so.

- **std's API takes slices, not `void*` or pointer + length pairs** ([#76](https://github.com/safec-org/SafeC/pull/76), [#80](https://github.com/safec-org/SafeC/pull/80), [#81](https://github.com/safec-org/SafeC/pull/81)). Buffers are `[]T` / `[]const T`, callback contexts are typed `?&T` stored as `?&Erased`, and no `void*` is left anywhere in std. Allocators hand out `?&heap unsigned char`; audio and MIDI callback contexts must be `Send + Sync`.
- **Compiler-enforced `Drop`, `Send` and `Sync`** ([#77](https://github.com/safec-org/SafeC/pull/77)). A value of a `Drop` type must be dropped or moved exactly once on every path; `spawn`, channels and thread pools accept only data that is safe to share or move.
- **Containers own their elements** ([#83](https://github.com/safec-org/SafeC/pull/83)). `clear()`, `drop()` and overwriting a key drop the values; don't free them yourself first.
- **std headers are `<std/...>` only** ([#83](https://github.com/safec-org/SafeC/pull/83)). safeguard no longer puts `std/` itself on the include path, so a bare `<math.h>` is the C library's and `#include <io.h>` must become `#include <std/io.h>`.

### Migrating {#migrating}

1. **Buffers:** pass slices — `f.read(buf[..])`, `w.write(buf[0..n])`, `sha256(bytes, digest[..])`, `str_copy(dst[..], src)`; `safe_memcpy` now counts elements. See [Types: slices](/reference/types#slice-types), [read-only](/reference/types#read-only-slices) and [optional slices](/reference/types#optional-slices).
2. **Ownership:** add `defer v.drop();` after creating a value of a `Drop` type (or release it on every path), and move data into threads with `thread_spawn` or share it through `Mutex<T>`. See [Ownership & Drop](/reference/ownership) and [Thread Safety](/reference/threads).
3. **Containers:** drop the container alone — remove any `m.foreach(free_value)` before `m.drop()`. See [Collections: containers own their elements](/stdlib/collections#ownership).
4. **Includes:** replace `#include <io.h>` / `"prelude.h"` with `#include <std/io.h>` / `<std/prelude.h>`. See *Including std* in [Standard Library Modules](/advanced/safeguard#standard-library-linking).
5. **Custom allocators and hashers:** switch `alloc` / `dealloc` to `?&heap unsigned char`, and a user `Hasher` to the slice signatures.

The full before/after table and two runnable examples are in [What's coming next: Migrating](/blog/whats-coming-next#migration); the changelog's *Breaking changes* section lists every changed signature, module by module.

## Upgrading {#upgrading}

Re-run the installer to upgrade an existing install in place (it installs the newest release, pre-releases included; pass the version to pin this one):

```bash
curl -fsSL https://raw.githubusercontent.com/safec-org/SafeC/main/install.sh | bash -s -- --version=v1.0.0-beta-7
```

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/safec-org/SafeC/main/install.ps1))) -Version v1.0.0-beta-7
```

Keep your std sections with `--std=...` / `-Std ...`, or add one later with `--std=+<section>`; see [Install](/install#options) for every option. Then check what you have:

```bash
safec --version       # safec 1.0.0-beta-7
safeguard --version   # safeguard 1.0.0-beta-7
```

Rebuild your projects from clean (`safeguard clean && safeguard build`) so nothing compiled against the old std is linked in.

## Known issues {#known-issues}

This is known in 1.0.0-beta-7:

- **GPU backends are compile-tested only.** The CUDA, ROCm, Metal, Vulkan and WebGPU paths in `std/ml` and `std/gui`'s GPU presenters compile in CI on every platform, but this release has not been run on GPU hardware.

If you hit something else, please [open an issue](https://github.com/safec-org/SafeC/issues).
